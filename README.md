# Geometry Algorithms

A curated collection of computational geometry implementations focused on correctness, clarity, and competitive-programming practicality.

## Highlights

- Clean implementations of core geometry primitives
- Robust use of integer arithmetic (including `__int128` where needed)
- Useful as a quick reference for common geometry problems

## Included Topics

| Topic | Folder |
|---|---|
| Polygon area (ordered/unordered) | `Area of Polygon` |
| Point orientation / turn test | `Orientation Check` |
| Line segment intersection checking | `Line Segment Intersection checking` |
| Point in polygon (ray casting) | `Point in Polygon using ray casting algorithm` |
| Sweep line methods | `Sweep Line algorithm` |
| Closest pair (sweep line) | `closest pair distance using  sweep line algorithm` |
| Closest pair (divide and conquer) | `closest pair distance using divide & conquer` |
| Convex hull (Andrew’s monotone chain) | `convexHull using Andrew’s Monotone Chain Algorithm` |
| Boundary/interior lattice points | `boundary and Interior LatticePoints` |

## How to Use

1. Open the folder for the target algorithm.
2. Reuse the implementation directly or adapt it for your project/problem.
3. Keep point/vector types consistent across reused snippets.
